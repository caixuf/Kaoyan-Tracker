## 🌟 2.0 全新升级亮点

1. 🌲 **考研技能树系统 (Skill Tree)**
   - 四科全景技能分支：【微积分破壁者】、【线代矩阵征服者】、【算法与指针行者】、【并发与PV调度师】、【词根解码者】、【长难句解构师】、【唯物辩证通】等。
   - 包含 Lv 1 ~ Lv 5 进阶体系，通过研读考点、记录错题、番茄专注自动获取 EXP（经验值）升级技能！

2. 📖 **全科内置学习知识库 & 手册 (Study Materials)**
   - **考研数学**：常用麦克劳林/泰勒展开式、八大等价无穷小、矩阵秩的不等式、六大常见概率分布特征表。
   - **计算机408**：八大经典排序时空复杂度与稳定性速查表、操作系统生产者-消费者PV模型标准代码模板、TCP三次握手与四次挥手状态机图解。
   - **考研英语**：高频前缀词根速查表、大小作文万能高分功能句库。
   - **思想政治**：辩证法对立统一答题大招、近代史纲要核心会议与历史转折全景表。

3. 🎯 **考点沉浸式深度精讲**
   - 考点大纲中支持点击「📖 精讲」即时展开详细知识点解析、解题套路与避坑指南，研读后奖励 **+50 技能经验值**！

4. ⏳ **考研初试精准倒计时 & 每日金句**
   - 秒级倒计时，自定义目标院校与专业。

5. 📝 **智能错题集与高频踩坑集**
   - 错因剖析、正确思路模板、1~5 星掌握度评级、快速筛选与检索。

6. ⏱️ **番茄钟专注学习与声音提示**
   - 25分钟专注 / 5分钟休息循环，绑定科目与任务，基于 Web Audio API 提示音。

7. 📊 **打卡热力图与复习日报导出**
   - 过去 42 天学习打卡贡献热力图，一键导出 Markdown 格式《今日复习日报》。
   - LocalStorage 自动持久化 + JSON 一键备份还原。
