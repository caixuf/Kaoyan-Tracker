## 🌟 核心特色一览

1. 🌐 **全网高星开源考研宝藏库 (Awesome Kaoyan Hub)**
   - 整合 GitHub 上数千 Star 的顶尖考研开源神库：
     - **408 计算机**：`CodePanda66/CSPostgraduate-408` (5.7k+ ⭐)、`xiaolei565/aimto408` (4.6k+ ⭐)、`408Bester`
     - **考研数学**：`TsekaLuk/Kaoyan-Math1-Papers` (1987-2025 真题 Markdown + LaTeX)、`CheapMeow/Math302`
     - **考研英语**：红宝书 5500 Anki 卡组、真题 1500 核心词频库
     - **思想政治**：1000 题核心考点精编、史纲会议全景时间线
   - 提供直接跳转、在线研读与 Anki 牌组链接。

2. 🌲 **考研技能树系统 (Skill Tree)**
   - 细分四大主线学科能力分支：【微积分破壁者】、【线代矩阵征服者】、【算法与指针行者】、【并发与PV调度师】、【词根解码者】、【长难句解构师】、【唯物辩证通】等。
   - Lv 1 ~ Lv 5 成长体系，通过研读考点资料、完成番茄钟打卡与攻克错题自动累积 EXP 并升级！

3. 📖 **全科内置精选学习知识库 & 手册 (Study Materials)**
   - **考研数学**：常用麦克劳林/泰勒展开式速查、八大常用等价无穷小、24 个基本不定积分全景公式表、矩阵秩的不等式。
   - **计算机408**：八大经典排序算法时空复杂度与稳定性全景表、操作系统经典 PV 同步互斥模型代码模板、TCP 三次握手与四次挥手状态机。
   - **考研英语**：高频前缀词根速查表、大小作文万能高分功能句库。
   - **思想政治**：辩证法分析题万能原理组合、中国近现代史核心会议与历史转折全景表。

4. 🎯 **考点沉浸式深度精讲**
   - 考点大纲中支持点击「📖 精讲」即时展开详细解析、解题套路与避坑指南，研读后奖励 **+50 技能经验值**！

5. ⏳ **倒计时看板、错题本、番茄钟与 42 天打卡热力图**
   - 浏览器 LocalStorage 自动保存，支持一键导出/导入 JSON 备份及生成 Markdown 格式《今日复习日报》。
